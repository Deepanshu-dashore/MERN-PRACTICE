# Weather App (Week 2 – Days 6–7 Mini Project)

A clean and responsive live weather web application built using JavaScript Fetch API and Open-Meteo.

## Features
- Search live weather for any city worldwide
- Displays current temperature, wind speed, and weather condition
- Dynamic error handling for non-existent cities or empty input
- Responsive layout designed with clean minimal CSS
- Uses free Open-Meteo API (no private API key required)

## Technologies Used
- HTML5 (Semantic Structure)
- CSS3 (Public Sans font, Flexbox, clean styling)
- JavaScript ES6+ (Async/Await, Fetch API, DOM manipulation)

## API Source
- Geocoding API: [Open-Meteo Geocoding](https://geocoding-api.open-meteo.com)
- Forecast API: [Open-Meteo Forecast](https://api.open-meteo.com)
